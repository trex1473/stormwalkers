# Project notes

In this project, I am experimenting with selecting a location on a map and turning data about that location into sound.

There are currently two ways to generate audio:
- POWER: numerical weather data
- GIBS: colors from satellite imagery

A few things to keep in mind:
- An internet connection is required.
- NASA services can sometimes take a while to respond.
- Two nearby locations may correspond to the same POWER data grid cell.
- Sound generated from satellite image colors does not directly indicate air temperature.

If something goes wrong, noting the terminal error message and which button you clicked will make troubleshooting easier.
